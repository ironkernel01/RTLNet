## 1. The package

The **Package** is the demonstration form of the RTLNet H.264 High profile extension as
IronKernel distributes it: the demonstration bitstream for the Nexys Video board, with the
firmware inside it and with High profile limited to 30 minutes after each configuration,
and the guide. The Package contains no source code and no netlist of the High profile
extension. The Package is stored in the `demos` folder of the RTLNet repository; this file
covers the Package files only.
