## 1. The package

The **Package** is the demonstration form of the RTLNet H.264 High profile extension as
IronKernel distributes it: the `rtlnet_h264_hp` netlist with its 30-minute run limit, the
port stub, the simulation model, the demonstration bitstream and firmware for the Nexys
Video board, and the guide. The Package contains no source code of the High profile
extension. The Package is stored in the RTLNet repository; this file covers the Package
files only.

The RTLNet sources that the Package plugs into are licensed separately by `LICENSE.md`.
