# All H.264 RTL benches run in Verilator. Phase 2b-2 (Intra16x16 + transform + quantizer + CAVLC, per-macroblock I_PCM fallback):
# the unit benches check the CAVLC block coder (tb_rtlnet_h264_cavlc), the macroblock layer and nC with I_PCM macroblocks
# (tb_rtlnet_h264_mbcavlc), forward and inverse transform and quantizers (tb_rtlnet_h264_xform) and intra prediction
# (tb_rtlnet_h264_ipred) against reference functions written from the clause text, each with a +INJECT_FAILURE negative control.
# The encoder bench tb_rtlnet_h264_top needs generated input images and is run by the decoder harness entries below:
# h264_harness.ps1 runs every configuration (176x144 structure checks with 1 and 3 slices, bars, zeros, a 2-picture run, a
# small-ring run with a slow consumer, 176x144 on 2 engines, a QP and content matrix at 176x144 including QP 0 checker and noise,
# 1280x720 and 1920x1080 on 1 and 2 engines with 1, 2 and 4 slices at QP 18, 28, 38 and 51, including the uneven 23/22 band split
# at 720p) and decodes each stream with JM, OpenH264 and FFmpeg; each decoder must be byte-identical to the rebuilt picture and the
# PSNR of the rebuilt picture against the source must reach the floor of its (pattern, QP) pair (h264_psnr_floors.txt). The _neg
# entry is its negative control (one corrupted stream byte, all three decoder comparisons must fail); the _pcm entry runs the
# global I_PCM mode (MB_MODE 1: exact picture). The _burstneg entry is the negative control of the burst monitor (the DDR3
# rule: bursts only; the bench monitor fails on any single-beat read, index or rebuilt-picture transaction and prints the
# beat-count histogram per master): the bench must fail on the injected single-beat AW. The rebuilt picture is macroblock-tiled in
# memory (luma 256 B and chroma 128 B tiles, one burst each) and the bench de-tiles it for the decoder comparison; the strip_*
# configurations have widths that are not a multiple of the 4-macroblock input strip. Build the decoders once with
# h264_build_decoders.ps1.
